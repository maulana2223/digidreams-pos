# DigiDreams Space — Mini-POS & Order Engine

Aplikasi Point of Sale (POS) berbasis web untuk manajemen katalog produk, keranjang pesanan, validasi kode promo, kalkulasi PPN 10% secara server-side, pemotongan stok atomik, serta cetak struk digital.

## Tech Stack
- **Framework**: Next.js (App Router), TypeScript, Tailwind CSS
- **Database & ORM**: SQLite, Prisma 7 (`@prisma/adapter-libsql`)
- **Icons**: Lucide React
